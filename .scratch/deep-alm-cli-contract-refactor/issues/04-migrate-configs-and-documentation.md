## Answer

配置样例现按场景与环境命名：M5 两策略/四策略、本机 CPU 开发、论文导向
研究计划和单 GPU 银行 commissioning。配置是唯一实验输入：银行样例通过
`reference_bank.snapshot_path` 选择导入快照，`bank` 动作从配置读取它。中英文
README 与实现版勘误仅展示 `plan`、`run`、`evaluate`、`report` 的通用生命周期，
并明确本机、研究计划和银行 commissioning 各自不能支持的结论。
