# Deep ALM 论文披露输入与私有数据缺口

## 结论

现有 SNB CSV 加上论文正文，足以完成**不含互换、覆盖 5 年和 15 年期限的方法论复现**：可以重建历史收益率曲线、校准 HJM-PCA、模拟利率路径、实现资产负债滚动与约束、训练基准策略和 Deep ALM 网络。

这些材料不足以完成**原论文数值复现**。决定资产负债风险的初始 180 个月现金流向量、若干客户产品分布、银行绝对规模和部分业务参数没有公开。论文明确说精确组合因数据隐私未报告，数据可得性声明也说明数据属于合作银行。[论文，§2.1.3/Table 1，PDF p.7；Data availability statement，PDF p.37](../../../docs/Deep%20treasury%20management%20for%20banks.pdf)

因此，本项目可以合理声称“真实 SNB 市场数据 + 合成参考银行的方法论复现”，不能声称重现合作银行或论文表格中的原始数字。

## 分类口径

- **直接披露（D）**：论文或 CSV 明确给出的值、公式或规则。
- **可推导（R）**：可由已披露内容唯一或近乎唯一地算出，但不是源文件中的现成字段。
- **私有/未公开（P）**：论文明确表示由银行提供、因隐私未公开，或属于未公开的数据集。
- **未说明/有歧义（U）**：论文没有提供足够实现细节，但不能据此断言该内容属于私有数据。

把 P 与 U 分开很重要。P 需要合成参考银行数据或取得授权数据；U 需要记录实现选择并提供“论文口径/修正口径”，不能伪装成从论文读出的事实。

## 二、论文直接披露的数据和规则

### 2.1 时间、期限和动作空间

| 项目 | 直接披露值 | 复现含义 |
| --- | --- | --- |
| 决策频率 | 每月，`Δt=1/12` 年 | 每月滚动、决策、重构 |
| 模型期限 | `T=5` 或 `15` 年 | 两个独立训练设定 |
| 时间步数 | `H=60` 或 `180` | 末期只滚动，不再重构 |
| 现金流最大期限 | `N=180` 个月 | 每个现金流组合是 180 维向量 |
| 投资债券 | `bB=13`，期限 3–15 年 | 每个整年期限一种 |
| 融资债券 | `bK=16`，期限 3 个月和 1–15 年 | 不含互换时动作维度为 29 |
| 交易限制 | 非负、可分数交易、持有至到期、不能卖空 | 网络输出最终使用 ReLU |

### 2.2 初始经济资产负债表的相对规模

| 资产 | 占总资产 | 负债与权益 | 占总资产 |
| --- | ---: | --- | ---: |
| 现金 | 20% | 非到期存款 | 10% |
| 投资 | 5% | 定期存款 | 40% |
| 抵押贷款 | 55% | 债券融资 | 40% |
| 企业贷款 | 20% | 权益 | 10% |

### 2.3 债券、贷款、存款和成本

| 模块 | 直接披露规则 |
| --- | --- |
| 投资/融资债券 | 新债按面值发行；半年付息；票息由当前贴现曲线解出，使无摩擦价格为 1；投资年化价差 `κB=-15 bp`，融资年化价差 `κK=+15 bp`。 |
| 贷款规模 | 新发贷款总额等于当月到期本金加现有贷款余额的 `3%/12`，所以组合年增长略高于 3%。 |
| 企业贷款期限 | 新发企业贷款在 1、2、3 个月期限间等分。 |
| 抵押贷款期限 | 新发抵押贷款分配到 2–12 年共 11 个整年期限；分布固定。后文仅进一步披露“大约 40%”的新抵押贷款为 10 年期。 |
| 信用损失 | 抵押贷款无违约。每年末，如 6 个月利率过去一年上升 `k>2%`，企业贷款按 `k-2%` 比例减值，并按当前组合比例分摊；减值部分不再付息。 |
| 存款期限模型 | 每笔存款使用参考期限 `{1个月, 2个月, 1年, 10年}`；到期金额等分滚入从 1 个月到参考期限的月度梯级。 |
| 存款增长 | 非到期存款年增长 4%；定期存款年增长 1%。 |
| 存款利率 | 参考率为 6 个月收益率的 3 个月移动平均；非到期存款 `min(60%×参考率,3%)`；定期存款 `min(max(85%×参考率,参考率-0.25%),5%)`；月利息为 `exp(u/12)-1` 并再投资。 |
| 运营成本 | 仅分为人员和材料成本；材料成本每月不变，人员成本每年增长 2%。 |
| 现金负利率 | 现金不赚正利息；在短端为负时，超过 `30×MR` 的现金按短端负利率收费。 |
| 分红 | 每年把当年正利润的 50% 分给股东。 |

来源：[论文，§§2.2.1–2.3.4，PDF pp.8–10；§4.3.2，PDF p.31](../../../docs/Deep%20treasury%20management%20for%20banks.pdf)。

### 2.4 监管和收益约束

以下计算规则和界限都已披露：[论文，§2.4，PDF pp.10–11](../../../docs/Deep%20treasury%20management%20for%20banks.pdf)

| 约束 | 界限 | 已披露的简化计算口径 |
| --- | ---: | --- |
| `E/RWA` | ≥17% | `RWA=10%×投资+35%×抵押贷款+100%×企业贷款` |
| LCR | ≥105% | `HQLA=71%×现金+89%×投资`；`NO30=17.6%×非到期存款+13%×定期存款+1%×融资` |
| NSFR | ≥105% | `ASF=95%×非到期存款+90%×定期存款+60%×融资+100%×权益`；`RSF=12%×投资+71%×贷款` |
| CMR | ≥100% | `MR=2.5%×(非到期存款+定期存款×(1-80%×1{1个月利率≥0}))` |
| IRS | ≤8.5% | 资产负债按收益率曲线平移 ±100 bp 重估后，取权益绝对变化率 |
| EYR | ≥0 | 每年 `(权益变化-mCHF 6)/上年权益` |

约束的简化权重由论文直接给出，不需要另行采用完整 Basel 规则。它们是论文模型口径，不是监管认证口径。

### 2.5 收益函数、模型和训练

| 项目 | 直接披露值或规则 |
| --- | --- |
| 实际训练目标 | 只惩罚最终权益低于目标的平方损失，加累计约束惩罚；高于目标不受罚 |
| 训练目标回报 `µ` | 每条路径从 `[2%,7%]` 均匀采样，并作为网络特征 |
| 训练惩罚权重 `λ` | 每条路径从 `[0.05,25]` 均匀采样，并作为网络特征 |
| 评估参数 | `λ=3.5`；5 年主模型 `µ=4.06%`；15 年主模型 `µ=4.00%`；CRRA 评估 `γ=10` |
| 单约束权重 | 按 `(LCR, NSFR, CMR, E/RWA, IRS, EYR)` 为 `[1.0,0.2,1.0,2.5,2.0,0.002]` |
| 收益率曲线特征 | 对训练路径中的曲线另做 PCA，压缩到 3 维 |
| 组合特征 | `Bpre,Kpre,R,S` 各用独立全连接编码器；输入组合先除以 100；每个编码为 32 维，隐藏编码层为 64 维 |
| 其他特征 | 5 个资产负债比例、6 个上一期约束特征、`t/T`、采样的 `µ` 与 `λ` |
| 输入维度 | 由 `4×32+3+5+6+1+2=145` 可推导，并与附录 `d=145` 一致 |
| 主网络 | 隐藏层 `[512,512,256,128]`、ELU、残差连接；最终编码 `d'=64` |
| 输出 | 以预训练 BMD 决策为基准，分别学习投资/融资的偏离规模和 softmax 期限分布，再经 ReLU |
| 跨时点参数 | 共享同一决策网络；输入 `t/T` 表示时间 |

### 2.6 HJM-PCA 场景生成

直接披露的配置和算法为：[论文，§§2.7.2–2.7.5 及 Table 2，PDF pp.14–16](../../../docs/Deep%20treasury%20management%20for%20banks.pdf)

1. 用 Svensson 六参数还原历史 CHF 即期收益率曲线。
2. 转换为历史远期曲线，按周计算变化，协方差乘 52 年化。
3. 保留前三个主成分；论文文字要求以对应特征值缩放特征向量。
4. 对三个期限载荷分别拟合三次多项式，形成常数时间、期限相关的 HJM 波动率矩阵 `V`。
5. 假设真实测度与风险中性测度相同 `P=Q`，按无套利条件从 `V` 得到 HJM 漂移，积分使用梯形法。
6. 远期曲线使用论文式 (41) 演化，期限导数采用前向差分；贴现因子按离散远期利率累加后取指数。

这使得 HJM 的拟合结果（历史曲线、协方差、PCA 载荷、多项式系数）属于 **R：可从 CSV 推导**，而不是需要银行数据的 P 类缺口。不过只有在下文的数值约定得到明确后，推导才可重复。

## 三、真正缺失或私有的输入

| 缺口 | 分类 | 为什么关键 | 复现处理 |
| --- | --- | --- | --- |
| 初始总资产 `A0`、权益和各项目的绝对 mCHF 规模 | P/未公开 | `mCHF 6` 的 EYR 缓冲和按 100 缩放的网络输入使绝对尺度会影响结果 | 为参考银行选定明确绝对规模，不只把资产机械归一化为 100 |

| 初始投资债券和融资债券的 180 月现金流向量 | P/未公开组合 | 决定每月到期规模、基准滚续规模和初始利率敏感度 | 合成与 Table 1 规模相符的遗留组合 |
| 贷款客户价差 `κL` | U，可能是银行特定参数 | 决定贷款利润和直接匹配融资是否有套利式收益 | 设为显式配置并做敏感性分析；不能声称为论文原值 |
| 初始材料成本和人员成本 | P/未公开 | 决定现金、利润、分红和 EYR 约束 | 设两项基准 mCHF/月，只让人员成本按已披露的 2% 年增 |

| 预训练 BMD 的最终参数 | U/未发布 | Deep ALM 输出以 BMD 为基准 | 在同一参考银行和训练分布上重新训练 BMD |

## 四、非隐私但必须决策的实现歧义

这些不是额外数据集，却会妨碍逐数值复现。

| 歧义 | 论文证据 | 建议记录的两种口径 |
| --- | --- | --- |
| PCA 载荷缩放 | §2.7.5 写成 `λj Q(j)`；通常协方差因子使用 `sqrt(λj) Q(j)` | `paper_literal=eigenvalue`；`corrected=sqrt_eigenvalue` |
| 周度样本定义 | 只说 weekly，未说星期几、节假日、周内最后有效值及协方差自由度 | 固定“每周最后有效观测”和样本协方差，并在报告中披露 |
| 从 Svensson 即期曲线到离散远期曲线 | 论文没有给精确离散转换式 | 分别实现由贴现因子相邻比值得到的远期率，以及论文可能使用的数值导数口径 |
| ALM 月度步长与 HJM 周度校准的换算 | 校准说 weekly，资产负债决策为 monthly；未明确模拟时如何统一 | 以年为单位统一 `dt`，将年化 `V` 用月度布朗增量推进；另保留周度推进后月末抽样的验证实现 |
| HJM 期限网格右边界 | 脚注只说先模拟更长曲线再逐步降维，未给额外期限数和实现顺序 | 额外期限至少覆盖整个模拟期，并写成配置/测试 |
| 贷款“月利息”公式 | §2.2.2 称其为 monthly payment，但式 (9) 为 `(exp(Y+κL)-1)+`，没有 `/12`；存款式 (12) 明确使用 `/12` | `paper_literal` 与 `monthly_corrected` 分开 |
| 定期存款增长符号 | §2.2.3 把 1% 写为 `ρSD`，附录另定义 `ρSF` | 将 1% 解释为 `ρSF`，同时保留勘误记录 |
| 企业贷款/个人贷款名称 | 定义使用“loans to enterprises”，违约段落却写“loans to individuals” | 统一为企业贷款，并记录论文用词不一致 |
| 重构后的现金更新 | 式 (18) 只出现单个债券价值，未写动作数量与求和；式 (17) 明确按动作数量增加组合 | 修正口径按全部动作的购买/发行面值更新现金；论文原式只用于勘误测试，不宜作为主实现 |
| 年末步骤索引 | 文字说每 12 个月及整年末，Algorithm 1 的 `i mod 12=0` 表面上会命中 `i=0` | 以月末 12、24…执行，并用边界测试固定顺序 |
| 收益率特征 PCA | 只说在训练数据的一个子集上拟合，未给子集大小、抽样或标准化 | 固定训练子集、只在训练集拟合并保存变换器 |
| 训练细节 | 未给权重初始化、RAdam 其余参数、循环周期/模式、early stopping 规则、PyTorch 版本 | 全部写入本项目配置和实验元数据，不把新选择标成论文原值 |

来源：[论文，§§2.2–2.7、3.2.1–3.2.4，PDF pp.8–16、18–22](../../../docs/Deep%20treasury%20management%20for%20banks.pdf)。

## 五、可推导但应落盘的中间数据

在数值口径确定后，下列产物都能由公开 CSV 和论文规则生成，不应手工硬编码：

1. 论文窗口内清洗后的日度六参数宽表。
2. 1–180 个月即期收益率、贴现因子和远期曲线。
3. 周度远期曲线变化、年化协方差、前三个特征值/特征向量。
4. 三个三次多项式及其在期限网格上的 `V`。
5. HJM 漂移向量和固定种子下的 5 年、15 年场景。
6. 所有决策无关的贷款、存款和成本路径。
7. 四个组合编码加其他特征构成的 145 维网络输入。

每个产物都应记录源文件哈希、日期窗口、缺失值规则、单位转换、随机种子和配置版本。

## 六、参考银行的最小假设登记表

进入实现规格前，至少要明确以下合成输入：

1. 绝对总资产规模和 mCHF 单位。
2. `RP0, RE0, B0, K0, SD0, SF0` 六个初始 180 月现金流向量的构造规则。
3. 抵押贷款 11 个期限权重、两类贷款的新发金额拆分。
4. 两类存款在四个参考期限上的权重。
5. `κL`、初始材料成本和人员成本。
6. `Y0` 日期以及存款参考率所需的前三个月历史值。
7. 上节所有 U 类歧义的默认口径和替代口径。

合成数据必须通过以下最低勾稽：资产负债恒等式；Table 1 粗略占比；贷款最长 15 年且久期小于 5 年；存款最长 10 年且久期小于 3 年；所有名义现金流和动作符号符合模型约定。

## 七、对 Wayfinder 的决策建议

1. 将项目目标正式定义为“方法论复现”，以新生成的训练/验证场景和参考银行为实验对象。
2. 将论文 Table 3–5 用作**方向性外部基准**，例如 Deep ALM 应优于 BMD、15 年模型的策略应比 5 年模型更平滑；不要把表中数值作为必须逐项相等的验收标准。[论文，§4 及 Tables 3–5，PDF pp.21–34](../../../docs/Deep%20treasury%20management%20for%20banks.pdf)
3. 先冻结“参考银行数据规范”和“论文口径/修正口径登记表”，再写资产负债模拟器。否则训练结果变化时无法判断来自模型、数据还是口径。
4. 不含互换的范围无需任何互换持仓、价差、限额或估值输入；动作始终保持 29 维。
